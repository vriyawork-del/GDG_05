# GDG on Campus MMMUT: Community Landing Page
Prompt2Pixel Round 2, Problem Statement 1.

## Folders
- `frontend/` the website: `index.html`, `style.css`, `script.js`, `images/`
- `backend/` the Node + Express server: `server.js`, `package.json`
  - `backend/serverless/join.js` an alternative version of the join API for Vercel (not used by default)

## Run locally
```
cd backend
npm install
npm start
```
Open http://localhost:3000

## Features
Responsive navbar with mobile menu, smooth scroll, hero with two CTAs, About with campus photos, project cards with category filter, event cards with register flow, testimonials, FAQ, join form with validation and backend, dark/light mode, animated stats.

Sample projects, events and testimonials are fictional. Demo contact details are marked as demo.
